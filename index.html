How to get a client ID (one time, free)
  1. Open console.cloud.google.com and create a project.
  2. APIs and Services, then Library: enable the Google Drive API.
  3. OAuth consent screen: choose External, fill the app name and your email, add your Gmail as a test user.
  4. Credentials, then Create credentials, then OAuth client ID, type Web application.
  5. Authorized JavaScript origins: add the address where you host this app, such as https://yourname.github.io
  6. Copy the client ID into the box above. The app only uses a hidden app folder in your Drive, never your other files.
